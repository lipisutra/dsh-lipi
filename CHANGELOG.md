# Changelog

## 1.0.0 — 2026-11-19

First release as `@lipisutra/dsh-lipi`.

- Tools `lipi_check`, `lipi_slice`, `lipi_map`, `lipi_graph`, and `lipi_new`.
- Host commands `/lipi-check`, `/lipi-slice`, `/lipi-init`, `/lipi-doctor`,
  `/lipi-map`, and `/lipi-lang`.
- Result cards in the chat and a status widget in the composer dock.
- The built-in `lipi` skill with references for every documentation edition.
- English and Russian documentation editions.
